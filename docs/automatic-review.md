# 자동 검수 운영 기준

매일 한국 시간 06:30 수집 후 자동 판정한다. 운영 반영 전 로컬 검증을 거친다.

- 자동 승인: 브랜드별 등록 공식 HTTPS 출처, 36시간 이내 정책 허용 확인, 상품별 NEW 또는 공식 신제품 발표, 검증된 출시/발표일 기준 30일 미만, 36시간 이내 실제 판매 확인을 모두 충족.
- 확인 필요: 근거 누락, 중복 ID, 미등록 출처, 출시일 불명, 미래 출시, 판매 불명. 기존 releaseDate, 최초 발견일, sitemap 수정일은 공식 날짜 근거로 승격하지 않는다.
- 자동 제외: 명시적 수집 제한, 검증 날짜 기준 30일 경과, 판매 종료/비활성. 이름 유사성만으로 다른 옵션을 중복 제외하지 않는다.
- 관리자 결정은 별도 파일에 유지하며 자동 판정보다 우선한다. 공개 목록의 판매/기간 필터는 계속 적용한다.

`reviewEvidence`는 수집기가 직접 검증한 정보만 기록한다. `sourceUrl`, `checkedAt`, `robots`, `explicitNew`, `officialLaunchAnnouncement`, `officialDate`, `dateKind`, `saleConfirmed`를 사용한다. 과거 데이터에 날짜·정책·판매 근거를 소급 추정하지 않는다. 현재 추가 브랜드 수집기는 정책 및 NEW만 기록하므로 출시일/판매 확인 전까지 대기하는 것이 정상이다. 미연결 수집기도 안전하게 대기한다.

알림은 GitHub Actions에서만 전송한다. 상품 ID+사유별 최초 1회, 한국 날짜별 최대 하나의 GitHub 이슈로 묶는다. 관리자 결정 및 자동 승인/제외 건은 알리지 않는다. 당일 추가 항목 및 본문 한도 초과분은 다음 날로 넘긴다. 알림 상태와 이슈 내 마커로 재실행 중복을 방지한다. GitHub 알림 수신은 저장소 구독 설정에 따른다. 로컬 `npm run review:notify`는 전송 없는 미리보기다.

추가 브랜드별 실패 및 작업 전체 실패를 알린다. 기존 수집기의 내부 부분 실패가 단순 경고로만 끝나는 경우는 아직 개별 실패 알림 대상이 아니며, 각 수집기 상태 보고 연결이 추가로 필요하다.
