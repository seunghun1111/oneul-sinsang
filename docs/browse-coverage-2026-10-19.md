# 공식 분류 교차 탐색·브랜드 수집 범위

## 상품 분류

- 원본 `category`·공식 `subCategory`·상품 ID·최초 발견일·검수·저장 기록을 변경하지 않고 탐색 범위만 확장했다.
- 정확한 CU 공식 HTTPS 출처와 브랜드·편의점 분류가 일치할 때만 공식 상품군을 교차 노출한다.
- 간편식사/즉석조리 → 식사, 과자류/아이스크림 → 간식·디저트, 음료/생활용품 → 음료·기타.
- 포괄적인 `식품`은 이름으로 추정하지 않고 편의점에 유지. 세븐일레븐의 `신상품`, 이마트24의 포괄적 분류 역시 임의 교차 분류하지 않는다.
- 편의점 전체 목록을 유지하며 홈페이지 카테고리 건수에도 같은 규칙을 적용한다. 메뉴별 건수는 겹칠 수 있음을 안내했다. 전체 공개 상품 수·주간/월간 집계는 중복 증가하지 않는다.
- 상세의 원래 소속 및 요약 상품군 링크는 원본 카테고리를 기준으로 유지한다.

## 수집 범위 안내

- 새 `/sources/` 페이지에서 47개 수집 항목을 확인한다. 홈페이지 소개·카테고리별 안내에서 접근 가능.
- 등록된 메뉴/MD/공식몰/공식 발표 경로와 실제 공개 상품의 분류·개수, 수집 시도 시각, 범위 한계를 분리했다.
- MD 전용 경로 미등록을 전체 MD 미지원과 동일시하지 않는다. 메뉴 경로에 MD가 포함될 가능성은 별도 확인 사항으로 표시한다.
- 정상 공개 0개, 후보 수집 후 공개 0개, 실패, 부분 실패, 오래된 기록, 미기록을 구분한다. 실패/미확인을 상품 없음으로 표시하지 않는다.
- 클라이언트에서 기록의 36시간 경과 여부를 재계산한다. 상품·보고서 데이터는 마지막 배포 시점의 스냅샷이며 이 화면은 수집을 실행하지 않는다.
- 범위 안내에는 상품 전체 정보 대신 브랜드·분류·출처 유형만 전달한다. 수집 경로 등록이 전체 상품 수집 성공이나 판매 보장을 뜻하지 않도록 기존 문구도 수정했다.
