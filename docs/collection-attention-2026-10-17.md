# 수집 운영 ‘확인 필요’ 전수 점검

2026-10-17, 로컬 점검·보완 완료 / 운영 배포 전.

기존 확인 필요 **14개 브랜드를 모두 실제 수집기로 점검**했다. 전체 등록 경로 교차 점검에서 매머드커피의 TLS 오류도 추가 발견했다. 로컬 운영 기록은 기존 14→9개, 추가 발견 1개를 포함해 **10개가 확인 필요**다. 5개 브랜드의 정상화는 현재 경로·상품 구조를 확인했다는 뜻이며, 새 상품 추가나 전체 상품 범위 수집을 의미하지 않는다.

## 공통 수정

- `npm run check:attention`: 확인 필요 브랜드를 실제 수집기로 경로별 진단, `docs/collection-attention-current.json` 저장. 상품·운영 기록·검수·알림에는 영향 없음. 미지원 수집기는 not_supported로 명시한다.
- `npm run update:coffee -- --attention`: 확인 필요 커피 브랜드만 재수집한다. `--source`와 동시 사용은 금지한다.
- 특정 브랜드 재수집 시 다른 브랜드의 확인 시각이 최신으로 바뀌던 문제 수정. 보고서 행에 checkedAt을 기록하고 미점검 행은 이전 시각을 보존한다. 운영 현황도 행별 시각을 우선 사용한다.
- 잘못된 행별 날짜는 그룹 보고 시각으로 숨기지 않고 not_checked로 처리한다. 이전 형식 보고서는 그룹 시각을 사용해 호환한다.
- 기존 NEW 0건 급감 보호, 수동 검수 우선, 최초 발견일 보존, 제한 경로 중단 정책 유지.

## 검증과 반영 범위

- 166개 테스트·타입 검사·867개 정적 페이지 빌드 통과. 공개 상품 855건, 데이터 무결성 오류 0건.
- 상품 파일·수동 검수·관리자 알림은 변경하지 않았다. 로컬 수집 상태·운영 보고서·정책/경로 진단만 갱신했다.
- 운영 배포는 하지 않았다. 배포 시 GitHub 수집 코드·데이터와 Sites의 공유 운영 현황 코드 모두 반영해야 한다. 기존 Site 비공개 권한을 유지해야 한다.
- 최종 실제 수집의 건강 상태와 진단 시점이 다를 수 있다. 모든 경로가 HTTP 200이어도 NEW 데이터가 수집됐다는 뜻은 아니다.

공식 대체 경로 연구: [투썸 공식 모바일](https://mo.twosome.co.kr/), [파스쿠찌 공식](https://www.pascucci.co.kr/index.asp), [커피베이 공식 메뉴](https://www.coffeebay.com/menu/coffeebay). 검색 결과만으로 수집 허용·NEW·판매 상태를 판정하지 않았다.
