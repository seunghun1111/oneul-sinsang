# 수집 재시도 및 진단 일치 보완

작업일: 2026-10-28 (Asia/Seoul). 로컬 개발·검증 결과이며 운영 수집 성공을 의미하지 않는다.

## 변경

- 이전 미배포 수정인 robots 일시 오류 캐시 만료 보완을 유지했다. timeout/connection/network 실패는 250ms 캐시 후 기존 최대 1회 재시도가 실제 요청을 보낼 수 있다. 정책 차단·TLS·DNS·HTTP 실패는 재시도 대상으로 확대하지 않았다.
- 예약 커피 수집과 개별 진단이 같은 collectCoffeeBrand 진입점을 사용한다. 스타벅스는 일반 HTML 수집기로 진단하지 않고 실제 음료/푸드/MD 전용 수집기를 한 번 실행한다.
- 스타벅스 HTTP 상태, robots/상품 본문 실패, JSON 구문 오류, 상품 필드 구조 변경을 정규화된 오류로 구분한다. 원문 응답과 원문 예외를 진단에 저장하지 않는다.
- 진단도 공통 재시도·부분 성공·빈 NEW 목록 보호 로직을 사용한다. 예외가 발생해도 다른 브랜드 진단을 중단하지 않으며 기존 상품은 변경하지 않는다.
- --brand 인자를 검증하고 중복을 제거한다. 정상 상태라 생략한 선택 브랜드를 skippedBrands로 기록한다. 개별 진단 미지원 항목을 정상 확인으로 안내하지 않는다.
- 선택 진단 결과는 전체 진단 파일과 분리한다. 이번에는 실제 외부 수집을 실행하지 않아 이전 진단 파일의 확인 시각을 갱신하지 않았다.
