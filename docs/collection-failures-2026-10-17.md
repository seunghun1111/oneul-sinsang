## 공통 보완

기존 보고서는 원문 예외를 버리면서 실패 유형까지 잃었다. 공통 전송에서 DNS·TLS·시간 초과·연결 오류를 허용된 코드로 바꾸고, robots 명시적 제한/정책 확인 불가와 구분한다. 카페 채널의 HTTP 오류와 부분 실패 코드도 기록한다. 일반 브랜드 실행기는 typed 오류 코드를 보존한다. 분류할 근거가 없는 예외는 unknown으로 남긴다.

원문 메시지·URL·스택·cause는 보고서에 복사하지 않는다. 승인 로직·기존 상품·수집 제한은 변경하지 않는다. 기존 상태 파일과 관리 화면을 과거 추측으로 채우지 않으며 상세 코드는 이 코드 적용 후 다음 수집부터 기록된다. 모든 파서 오류나 스타벅스 자체 검사 예외가 세분화되는 것은 아니며 unknown이 남을 수 있다.

현재 로컬 검증 상태. 배포와 재수집은 별도 승인 후 수행한다.
