# 확인 필요 경로 재점검 및 다음 운영 검증

## 범위

공개 공식 경로만 읽기 전용으로 진단했다. 상품 병합·자동 검수·알림·운영 상태 갱신·배포·Actions 수집 실행은 하지 않았다. 샌드박스 네트워크에서 일괄 DNS 실패가 발생한 첫 검사는 사이트 장애 근거로 사용하지 않고, 네트워크 허용 환경에서 다시 실행한 결과로 진단 파일을 갱신했다.

검증되지 않은 대체 주소로 자동 변경하지 않았다. 잔여 9개 브랜드가 복구된 것은 아니다. 상세 경로별 결과는 `collection-attention-current.json`에 기록했다. 정책·GET 응답 진단 파일도 별도 갱신하며, 응답 성공 자체는 NEW·판매 확인이 아니다.

## 공통 코드 보완

- 브랜드·커피 수집 보고서에 실제 `attempts`와 최초 실패 코드(`initialFailureCode` / `initialFailureCodes`)를 남긴다.
- 최초 실패 후 복구한 경우 최종 상태는 성공으로 유지하며, 최초 오류를 최종 실패 코드로 섞지 않는다.
- 재시도 최대 1회, 일시적 네트워크 오류에 한정하는 기존 정책을 유지한다. 부분 성공·빈 정상 응답·정책/TLS/DNS/HTTP/구조 오류는 추가 반복하지 않는다.
- 원문 오류·헤더·인증정보는 기록하지 않는다. 기존 보고서와 호환되도록 추가 필드는 선택 항목이다.

## 검증 및 남은 작업

- 테스트 213개 통과, lint 오류 0 (기존 img 경고 2개), 정적 빌드 949페이지 통과.
- 품질 total 1236 / published 934 / errors 0 / gaps 34. 상품 데이터는 변경하지 않음.
- 다음 배포 및 승인된 수집 실행 후, 보고서에서 실제 시도 횟수·최초 오류·최종 상태를 대조해야 운영 복구를 판정할 수 있다.
- 다음 실제 예약 실행에서 06:30 KST 대비 지연 분, 60분 이상 지연 알림, 기존 알림 중복 방지를 확인해야 한다. 수동 실행은 예약 지연 검증을 대체하지 않는다.
- 배포·운영 수집 실행 및 지속 모니터링은 이번 작업에 포함하지 않았다.
