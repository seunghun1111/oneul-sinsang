# 일일 수집 저장 충돌 보호

2026-10-16 실행(38825424671)은 수집 도중 main이 갱신되어 마지막 git push가 거절됐다. 배포 작업도 실행되지 않았다. 수집 실패와 저장 실패는 구분해야 한다.

게시 아티팩트를 올리기 전에 원격 main과 실행 시작 SHA를 비교한다. 다르면 실패로 중단하며 자동 rebase·강제 push·데이터 덮어쓰기는 하지 않는다. 검사 이후의 경합도 일반 push의 fast-forward 보호로 차단된다. 최신 main 기준으로 다시 실행해야 한다.

실패 시 브랜드 상태·정책·이미지·운영 진단 JSON만 7일간 Actions 아티팩트로 보존한다. 상품 전체, 환경 변수, 인증 정보는 포함하지 않는다. 저장 단계 뒤에도 실패 알림 경로를 두어 기존 알림 단계 이후 발생한 실패를 처리한다. 기존 하루 한 이슈 정책은 유지되므로 이미 당일 알림이 있으면 추가 사유는 다음 실행으로 이월될 수 있다. 아티팩트 업로드 자체가 실패하면 진단 파일은 보존되지 않을 수 있다.

이 변경은 로컬 구현 상태다. 배포 및 수집 수동 재실행은 별도 승인 후 진행한다.
