# 수집 품질 개선 — 2026-10-16

## 스타벅스

- 기존 sitemap 기반 발견을 공식 메뉴 화면이 사용하는 카테고리별 상품 응답으로 대체했다.
- 공식 화면의 `newicon === "Y"`만 NEW로 인정한다. 시즌, 품절, 최근 확인일을 NEW 근거로 대체하지 않는다.
- 음료·푸드·MD를 확인한다. 원두/VIA는 별도 경로이므로 이번 구현의 확인 범위가 아니다. 미지원 범위를 요청 실패로 집계해 영구 재시도 알림을 만들지 않는다.
- 공식 응답이 명시적으로 `newicon === "N"`인 기존 상품만 NEW 노출을 해제한다. 판매 종료를 의미하지 않으므로 판매 상태는 unknown으로 유지한다.
- 카테고리 하나라도 요청/스키마 검증에 실패하면 해당 섹션의 부분 결과로 기존 상품을 해제하지 않는다. 단순 누락도 해제 근거로 사용하지 않는다.
- 최초 발견일과 기존 상품 ID는 유지한다.

공식 사이트 읽기 전용 확인 결과: 전체 NEW 51건. 기존 관찰 상품 126건 중 NEW 유지 15건, 명시적 N 85건, 미확인 26건이었다. 기존 목록에 없던 NEW는 36건이다. 이는 확인 시점의 미리보기이며 운영 데이터 반영 결과가 아니다.

공식 이벤트 `https://www.hollys.co.kr/news/event/view.do?idx=569`에서 할리베어 MD 출시 안내를 찾았다. 다만 상품별 상세 정보가 이미지에 있어 현재 텍스트 수집기로 기존 MD 2건의 정확한 상품명·발표일 연결을 입증하지 못했다. 파일명에 포함된 날짜를 출시일로 간주하거나 MD 전체를 일괄 승인하지 않는다. 2건은 관찰을 유지한다.

## 식품 공식 발표

풀무원·오리온·매일유업·삼양식품·빙그레 공식 최신 발표 수집기를 읽기 전용으로 재실행했다. 각각 2·2·3·4·0건의 상품 후보가 반환됐다. 풀무원 서리태 두유의 공식 발표일은 2026-10-12이며 나머지 반환 후보 10건은 한 달 기준 밖이다.

이 결과는 최신 목록의 수집 범위에 한정된다. 기존 식품 관찰 15건 중 최신 결과에 없는 4건을 판매 종료 또는 근거 없는 상품으로 판정하지 않는다. 해당 개별 발표의 재확인은 후속 과제다.

## 반영 범위

이번 변경은 로컬 수집기와 회귀 테스트다. 운영 데이터 저장, 배포, 관리자 알림 발송은 실행하지 않았다. 배포 시 기존 일일 수집 흐름에서 동작하며, 실제 수집 및 자동 검수 결과는 실행 시점의 공식 응답에 따라 결정된다.
