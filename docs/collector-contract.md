# 공통 수집 계약과 브랜드 어댑터

브랜드별 파일은 공식 응답을 해석하는 어댑터다. NEW 배지 필드, 신메뉴 탭, 게시물 구조, 상품별 이미지 필드 매핑은 브랜드별로 유지한다. 사이트마다 의미가 다른 조건을 하나의 정규식으로 합치지 않는다.

## 공통 저장 경계

`scripts/lib/collected-product.ts`의 `normalizeCollectedProduct`를 두 저장 경계(`mergeProducts`, `mergeCoffeeProducts`)에서 사용한다. 따라서 편의점·햄버거·피자·치킨·아이스크림·식품·카페는 같은 정책을 공유한다.

- 공식 사이트 상품 이미지는 HTTPS 주소로 정규화한다. 자격증명 포함 URL, 실행·data URL, IP/내부 호스트 및 제한 도메인은 배제한다. 상대 경로는 상품 출처를 기준으로 해석한다.
- 새 이미지가 없거나 부적절하면 기존 정상 이미지를 보존한다. 파서 필드 누락 때문에 기존 이미지를 지우지 않는다.
- 상품 ID, 최초 발견일, 생성일, 수동 검수 이력, 초기 수집 구분을 보존한다.
- 가격은 저장하지 않는다. 기존 정책에 따라 보도자료 사진은 공개 데이터에 저장하지 않는다.
- 이미지 유무는 NEW·판매 여부의 승인 근거가 아니다. 이미지가 없다고 상품을 삭제하거나 자동 제외하지 않는다.

## 누락 감지

`report:collection`은 두 카탈로그 모두를 `auditCollectedImages`로 확인한다. 활성 공식 상품의 이미지 보유·누락 수를 브랜드별로 `collection-health.json.imageQuality`에 기록하고 누락이 있으면 실행 로그에 표시한다. 신상품 판별 알림과 분리하여, 정상 상품을 검수 대기로 바꾸거나 반복 관리자 알림을 보내지 않는다. 주소 저장 여부를 점검하는 것이며 실제 CDN 가용성 전체를 검사하는 것은 아니다.

## 어댑터 테스트 필수 항목

각 브랜드의 실제 응답 형식에 맞춘 표본으로 이름·식별자·공식 출처·NEW 근거·이미지 매핑을 검사한다. 이미지 필드가 없을 때에도 상품을 보존하며 공통 누락 집계에 나타나야 한다. 공통 저장 경계를 통과한 후 이미지와 기존 검수/발견 이력이 유지되는지도 검사한다.

스타벅스 어댑터는 공식 화면과 동일하게 `img_UPLOAD_PATH + file_PATH`를 조합하고 알려진 `image.istarbucks.co.kr/upload/store/skuimg/` 경로만 채택한다. NEW는 `newicon`으로 별도 판별한다.

일일 수집의 공통 저장 계약·이미지 정책·누락 진단, 기본 HTTP 전송을 통합했다. 후속 로컬 구현에서는 robots 확인·해석도 공통 계층에 연결했다(`collection-http.md` 참고). HTML 파서와 브랜드별 NEW 조건은 분리해 유지한다.

## 이번 검증 결과

스타벅스 NEW 51건 전부에 이미지 주소를 저장했다. 공식 이미지 CDN robots의 Allow 정책을 확인한 뒤 음료·푸드·MD 각 1개 표본의 HTTP 200 및 image/jpeg 응답을 확인했다. 로컬 정적 빌드의 실제 카페 화면에서도 상품 사진 표시를 확인했다. 기존 미확인 스타벅스 26건은 NEW나 이미지를 추측해 채우지 않았다.

공통 회귀 테스트를 포함한 114개 테스트, 타입 검사, 정적 빌드가 통과했다. 린트 오류는 없고 기존 img 최적화 권고 4건은 남아 있다. 운영 배포는 이 변경에 포함하지 않았다.

## 후속: 카페 HTML 이미지 연결

`coffee-images.ts`는 브랜드별 공식 카드 구조에서 이미지 후보를 읽고 공통 URL 정책으로 검증한다. 빽다방은 같은 슬라이드의 제목·사진, 이디야와 할리스는 상품 이미지의 정확한 alt와 정규화 상품명을 연결한다. 같은 이름에 서로 다른 이미지가 있으면 자동 연결하지 않는다. 상품명·경로가 없는 이미지, NEW 배지, 다른 호스트의 이미지는 제외한다.

일반 카페 수집기에 이미지 보완을 연결했고, `update:coffee-images`로 기존 상품의 이미지만 별도 보완한다. 이 단계는 고정된 공식 출처 3곳의 robots를 확인하고 리다이렉트를 따르지 않으며 응답 시간·크기를 제한한다. 일일 workflow에도 연결했지만 현재 변경은 아직 배포 전이다.

2026-10-16 로컬 재확인에서 빽다방 12건, 이디야 16건, 할리스 25건(총 53건)의 이미지를 보완했다. 이디야 7건은 미확인으로 유지했다. 전후 데이터 비교로 이미지 외 상품 필드가 바뀌지 않았음을 확인했다. 특히 이미지 연결을 NEW 승인·판매 확인·출시일 근거로 사용하지 않는다.
