# 상업 운영 전 점검 사항

현재 오늘신상은 비상업적 개인 프로젝트를 전제로 운영한다. 상업 운영으로 전환하기 전에는 아래 항목을 다시 검토한다.

## 필수 재검토

- 각 브랜드 웹사이트의 이용약관, robots 정책, 자동 접근 허용 범위
- 데이터베이스 제작자 권리와 반복적·대량 수집에 해당하는지 여부
- 브랜드명과 상표를 제휴·공식 서비스로 오인하게 표시하지 않는지 여부
- 상품 설명, 보도자료 문장, 사진 등 저작물의 복제 범위
- 광고·제휴 링크·유료 노출 도입 시 표시광고 및 전자상거래 관련 고지
- 문의 양식이나 회원 기능 도입 시 개인정보 처리방침과 보관·삭제 절차
- 수집 주기, 요청량 제한, 캐시, 연락처 및 삭제 요청 처리 기준

## 현재 적용한 제한

- 가격 데이터와 쇼핑몰 가격 수집을 하지 않는다.
- 외부 상품 이미지를 복제하거나 직접 표시하지 않는다.
- 공식 출처에서 확인한 상품명·출시/판매 상태와 출처 링크 위주로 제공한다.
- 공식 목록에서 두 번 연속 확인되지 않은 자동 수집 상품은 판매 종료 처리한다.
- 비제휴·비후원 관계를 표시하고 정정·삭제 요청 창구를 제공한다.

상업 운영 전에는 국내 변호사 또는 관련 전문가에게 실제 수집 방식과 화면을 기준으로 검토받는 것이 안전하다.
