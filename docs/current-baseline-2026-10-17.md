# 현재 범위 품질 정리 — 2026-10-17

## 상태

이 문서는 이번 로컬 정리 묶음의 기준이다. 운영 미배포이며 GitHub Pages와 비공개 Sites 게시에 별도 승인이 필요하다. 상품 JSON·수동 결정·알림 상태·접근 권한은 변경하지 않았다. 품질 수치는 docs/catalog-quality-current.json의 확인 시점 스냅샷이며 새 상품이나 시간이 지나면 달라진다.

## 수정한 불일치

1. 교촌 공식 신메뉴 탭(code=21) 근거로 자동 승인된 12개 상품이 공개 목록의 explicitNew 조건에 막혀 누락됐다. 정확한 브랜드·공식 경로·근거 코드를 확인하는 공통 함수를 자동 검수·공개 필터·근거 표시에서 사용한다. 임의의 officialNewListing 문자열은 허용하지 않는다. 검수 대기·제외·비활성 상품은 여전히 숨긴다. 로컬 공개 수는 843→855건이다.
2. 운영 현황의 not_checked가 확인 필요 필터에 잡히지 않았다. 기록 없음도 확인 대상으로 포함한다. 허용된 DNS·TLS·HTTP·정책·구조 오류 코드만 고정 문구로 표시하고 원문 오류는 노출하지 않는다. 상세 사유는 변경된 report:collection 실행 후 생성되며 과거 JSON을 추측으로 다시 쓰지 않았다.
3. 홈 날짜 탭에 선택 탭만 Tab 진입, 방향키 순환, Home/End 이동, 탭-패널 연결, 날짜·건수 접근성 이름을 추가했다. 실제 브라우저에서 방향키·Home과 0건 안내를 확인했다. 기존 날짜별 집계·스크롤·더보기 동작은 유지한다.
4. README의 오래된 30일·판매 확인 일괄 조건과 모든 변경의 DB 마이그레이션 요구를 정정했다. 최근 공식 발표 자동 승인과 공개 NEW 노출이 완전히 같은 집합은 아니라는 제한도 명시했다. 발표를 공개 NEW로 넓히는 정책 변경은 하지 않았다.
5. check:quality를 추가하고 공개 배포·일일 수집의 빌드 전에 파일 변경 없는 --check로 연결했다. 중복/누락 ID·가격 필드·깨진 필수 날짜·위험한 공개 출처는 실패시킨다. 이미지 누락·분류 누락·36시간 확인 지연은 경고로 구분하며 임의로 상품을 승인·제외하거나 알림을 보내지 않는다.

## 보존한 제한과 남은 검증

- 최근 경로 점검은 47개 브랜드·64개 진입 경로다. 48곳 GET 응답 정상, 12곳 정책 보류, 3곳 POST 별도 확인, 1곳 HTTP 접근 거부였다. 이는 앞선 점검 시각 결과이며 이번에 브랜드 사이트를 전부 다시 요청하지 않았다. 페이지네이션·모든 동적 API·상품별 NEW 추출 성공률을 증명하지 않는다.
- 롯데리아·엔제리너스·할리스 스토어 제한 및 정책/TLS/DNS 오류는 우회하지 않는다. 기존 공개 상품 보존은 현재 판매·NEW를 실시간 재확인했다는 의미가 아니다.
- 세븐일레븐의 기본 이미지·정책 제한 경로, 이디야의 같은 이름에 서로 다른 이미지가 매칭되는 항목은 추측하지 않는다.
- 공차 캠페인 이미지·컴포즈 추천 메뉴·테라로사 일반 목록을 NEW로 일괄 승격하지 않는다. 동적 데이터와 앵커 밖 배지는 미지원일 수 있다. 피자헛은 정확히 확인된 개별 이미지 대체 근거만 사용하며 브라우저 자동 렌더링 수집은 아니다.
- 이번주/이번달의 초기 수집 제외 전환일은 2026-10-19로 유지한다. 날짜 집계와 NEW/판매 상태는 별개다.
- 자동화의 정상·부분 실패·전체 0건 보존·중복 알림·수동 결정 우선은 기존 테스트로 회귀 검사했다. 새 외부 수집/전체 일일 실행/알림 전송은 하지 않았다.
- 실제 iOS/Android 터치·키보드 및 모든 모바일 폭의 전체 시나리오를 이번 묶음에서 재검증한 것은 아니다. 기존 320/375px 점검과 이번 데스크톱 키보드 조작을 구분한다. 통합검수함은 로컬 타입 검사까지 완료했으며 실제 hosted 화면은 게시 후 확인해야 한다.
