# 발견·출시·판매 근거 분리

## 적용 범위

- 공식 상품별 NEW와 교촌 공식 신메뉴 탭 승인 기준은 유지한다.
- 검수함에서 `브랜드 + 상품명`으로 네이버 출시 소식 및 판매·주문 검색을 직접 열 수 있다. 페이지를 열기 전 자동 검색 요청을 보내지 않는다.
- 신상 여부와 판매 여부는 별도다. 기존 `availabilityStatus: on_sale`, 판매처 이름, 공식 목록 존재만으로 판매 링크 확인을 표시하지 않는다.
- 검증된 출시일이 없는 상품은 최초 발견일을 표시한다. 기존 releaseDate는 출시일로 간주하지 않는다.
- 공식 NEW가 없는 검색 후보는 승인하지 않는다. 검색에 없다는 이유로 판매 종료시키지도 않는다.
- `discoveryReferences`에는 출시/판매 구분, 원문 URL, 확인 시각, 검증 여부를 별도 기록할 수 있다. 미검증 링크는 후보로 표시하며 자동 승인 로직에는 연결하지 않는다.
- 확인된 판매 링크도 매장 재고나 현시점 주문 가능 여부의 보증은 아니다. 기프티콘은 매장 메뉴 판매 증거가 아니다.

## 이번에 포함하지 않는 기능

네이버 검색 API 연결, 검색 결과 자동수집/후보 자동등록, 브라우저에서 근거 저장은 포함하지 않는다. 이번 배포는 수동 검색 보조와 근거 표시 분리 단계다. 별도 API 인증정보나 새로운 외부 서비스 연결은 추가하지 않는다.
