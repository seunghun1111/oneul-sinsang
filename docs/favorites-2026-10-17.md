# 관심 브랜드·상품 저장

2026-10-17 로컬 구현. 앞서 완료한 화면 후속 개선과 함께 배포 전 상태.

- 상품 목록과 상세의 별표로 관심 상품 저장·해제.
- 검색/카테고리/관심 화면의 ‘관심 브랜드 관리’에서 브랜드 저장·해제.
- `/saved/`에서 관심 상품 또는 관심 브랜드의 공개 NEW 상품을 모아본다. 검색·분류·정렬·컴팩트/카드/리스트·48개 더보기를 함께 사용한다.
- 헤더에 관심 목록 진입점 추가, 320px에서 검색·관심 버튼과 로고가 함께 표시되도록 보완.
- `localStorage`의 앱 전용 버전 키에 상품 ID와 브랜드명만 저장한다. 로그인·DB·외부 API·분석 도구는 추가하지 않는다. 같은 브라우저의 다른 탭과 화면에 변경을 반영한다.
- 잘못된 JSON·자료형·지원하지 않는 버전은 빈 목록으로 읽는다. 저장 읽기/쓰기 실패는 성공으로 표시하지 않고 버튼 아래 오류 안내를 제공한다.
- 상품 2,000개·브랜드 200개 한도. 새 저장이 한도를 넘으면 기존 기록을 밀어내지 않고 거부한다.
- 현재 공개 목록에서 사라진 상품은 모아보기에 노출되지 않으며 저장 ID는 자동 삭제하지 않는다. 저장 건수와 표시 상품 수는 다를 수 있다.

## 개인정보·제한

관심 목록 자체는 서버로 전송하지 않는다. 검색·분류 조건은 기존 기능과 마찬가지로 URL에 포함될 수 있다. 브라우저 저장 기록 삭제 시 관심 목록도 사라지며, 다른 기기·다른 브라우저·다른 origin으로 동기화되지 않는다. localhost의 검증용 기록은 GitHub Pages로 이전되지 않는다. 비공개 모드·저장 제한 환경에서는 지속 저장을 보장하지 않는다.

## 검증

- 테스트 184개 통과, 린트 오류 0(기존 img 경고 2), 타입 검사·정적 페이지 869개 빌드 통과.
- 실제 로컬 브라우저: 피자헛 상품 1개 저장 → 관심 목록 진입 → 새로고침 유지 → 다른 탭에서도 동일 목록 → 해제 후 양쪽 탭에 0개 반영.
- 교촌치킨 브랜드 저장 → 브랜드 모아보기 12개 표시 → 해제 후 0개 반영.
- 320px: 문서 너비=가시 너비=305px(스크롤바 제외), 가로 넘침 없음. 로고·검색·관심 진입점과 모드 버튼 표시 확인.
- 검증을 위해 직접 추가한 상품 1개와 브랜드 1개는 UI에서 해제했다. 기존 사용자 기록은 삭제하지 않았다.
- 저장 읽기 거부·쓰기 실패·한도는 가짜 저장소를 사용하는 단위 테스트로 검증했다. 운영 브라우저의 개인정보 설정을 변경하지 않았다.
- 실제 iOS/Android 기기 검증은 아니다. 상품 데이터·수집 코드·ChatGPT Site·권한 설정 변경 없음.
