# 관심 목록 백업·미노출 기록 관리

## 구현

- `/saved/`에서 JSON 내보내기·파일 선택·건수 미리보기·명시적 합치기·취소 제공.
- 기존 기록을 대체하지 않고 합집합으로 저장. 중복 제거, 상품 2,000개·브랜드 200개 한도 초과 시 전체 적용 거부. 기존 항목을 밀어내지 않음.
- 적용 순간 저장소를 다시 읽어 파일 선택 이후 다른 탭에서 추가된 기록도 보존. 동시 탭이 정확히 동시에 쓰는 경우까지 트랜잭션을 보장하는 구조는 아님.
- 파일 최대 1MB, 버전·배열·문자열 길이 엄격 검사. 읽기·쓰기 실패 및 잘못된 기존 저장소는 덮어쓰지 않음.
- 내보내기는 상품 ID·브랜드·형식 버전만 포함. 임의 추가 속성은 내보내지 않음.
- 파일은 브라우저에서만 처리하며 서버 업로드·계정 동기화 없음. 백업 파일 공유 주의 안내 포함.
- 현재 공개 상품에 없는 저장 ID와 브랜드를 별도 표시하고 개별 관심 해제 가능. 공개 목록 미노출은 판매 종료로 단정하지 않음. 이름을 알 수 없는 상품은 임의 추정 없이 ID로 표시.

## 검증

- 전체 테스트 197개 통과 (백업 관련 6개 추가), 린트 오류 없음·기존 img 경고 2개, 정적 빌드 869페이지 성공.
- 브라우저에서 QA JSON 선택 → 적용 전 상품·브랜드 0 유지 → 합치기 후 각각 1 → 미노출 기록 표시 → 개별 해제 후 0 복원 확인.
- 실제 브라우저 다운로드 파일 저장은 수행하지 않음. 내보내기 데이터 형식·불필요 속성 제거는 단위 테스트로 검증.
- 중복 제거·초과 용량·합친 뒤 한도 초과·저장 차단·손상 JSON·취소 UI는 테스트로 확인.
- 모바일 320px document scrollWidth/clientWidth 모두 305px. `favorites-backup-mobile.png` 저장 후 viewport 복원.
- `fixtures/favorites-backup-qa.json`은 재현 가능한 테스트 전용 기록이며 실제 관심 데이터가 아님. 테스트로 추가한 브라우저 기록은 모두 해제.
