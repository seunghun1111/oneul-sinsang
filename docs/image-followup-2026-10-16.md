# 잔여 이미지 누락 확인

## 이디야 7건

공식 음료 페이지에 동일 상품명과 서로 다른 이미지 파일이 중복 존재했다. 오트 커피 HOT/ICED L/EX 4건, 오트 콜드브루 ICED L/EX 2건, 가나 초코 소프트 아이스크림 아포가토 1건이다. 기존 데이터의 식별자는 상품명 기반이므로 공식 카드 ID와 일치한다고 단정할 수 없다. 임의의 첫 이미지 선택이나 파일명 날짜 비교로 채우지 않는다.

`coffee-image-status.json`에 상품 ID·상품명·`ambiguous_images` 사유·후보 이미지 수를 저장하도록 추가했다. 일일 수집 커밋에도 해당 보고서를 포함했다. 일치 이미지 없음(`not_found`)과 출처 확인 실패(`source_unavailable`)는 별도로 구분한다. 이 보고서는 NEW 검수 근거가 아니다.

## 세븐일레븐 5건

robots를 확인한 뒤 허용된 `/product/presentList.asp`의 신상품 응답에서 확인했다. 이미지 경로 자체는 요청하지 않았다.

- 105871, 106219, 108594, 113184: 공식 카드에서 `디폴트 이미지`를 제공했다. 실제 상품 사진을 확보한 것으로 처리하지 않는다.
- 104275: 공식 상품 이미지 URL은 존재했다. 그러나 해당 사이트 robots가 이미지 경로인 `/upload/`를 제한하므로 직접 요청·다운로드하지 않았다. 이번 작업에서는 새 이미지 URL을 추가하지 않았다.

공통 HTML 속성 읽기를 추가해 `alt`와 `src`의 순서가 바뀌어도 기본 이미지를 제외하고 `data-src`를 `src`로 잘못 읽지 않도록 했다. 이디야·할리스·빽다방의 이미지 해석과 세븐일레븐의 이미지 해석이 같은 속성 읽기를 사용한다.

현재까지의 보완은 로컬 변경이며 운영 배포 전이다. 기존 NEW·판매·수동 검수 판정은 유지했다.
