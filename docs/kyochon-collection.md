# 교촌치킨 수집 규칙

- 공식 신메뉴 탭: https://www.kyochon.com/menu/chicken.asp?code=21
- `code=21`은 신메뉴 분류다. 다른 code 또는 전체메뉴에 이 규칙을 적용하지 않는다.
- 2026-10-16 실제 화면에서 상품 이미지에 포함된 주황색 NEW 배지를 확인했다. HTML 텍스트 검색만으로는 이를 인식하지 못한다.
- 신메뉴 제목, code=21 활성 탭, menuProduct 내부의 상품 ID와 이름을 함께 확인한 경우 `officialNewListing: kyochon_code_21`을 저장한다.
- 공식 신메뉴 탭 등록을 승인 근거로 사용한다. 이미지 OCR에 성공했다는 의미로 `explicitNew: true`를 만들지 않는다.
- 자동 검수는 교촌 브랜드와 정확한 공식 URL, 일치하는 근거 URL을 확인한다. 차단 정책·종료·중복 식별자 검증은 그대로 적용한다.
- 제목/활성 탭 구조가 바뀌면 신메뉴 근거를 추정하지 않는다. 기존 수집 실패·전체 0건 보호를 유지한다.
- 출시일, 최근 30일 출시 여부, 매장별 재고·판매 여부를 보증하지 않는다. 관리자 수동 판정은 자동 판정보다 우선한다.
