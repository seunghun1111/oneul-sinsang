# 모바일 최적화

공개 페이지: 모바일 히어로 축소, 날짜별 건수 배지 겹침 제거, 카테고리/브랜드/세부 필터를 라벨 위·옵션 아래로 배치, 주요 조작 44px 터치 높이, 좁은 목록의 줄바꿈/최소 폭 보완, 상품명 두 줄, 상세 페이지 긴 제목 보호. 이번주/이번달의 확장 영역은 화면 높이 80svh를 넘지 않으며 모바일에서는 목록 끝에서 페이지 스크롤이 이어진다. 감속 선호 시 이동 애니메이션을 줄인다.

통합검수함: 700px 이하에서 검수 링크·일괄 동작 줄바꿈, 380px 이하 필터 1열, 입력 16px, 선택 영역 확대. 수집 현황 표는 표 영역만 가로 스크롤한다. 권한·검수·데이터 수집 로직은 변경하지 않았다.

로컬 브라우저에서 375px 홈과 320px 카페 컴팩트 화면을 시각 확인했다. 공개 페이지 빌드·전체 테스트·린트(기존 이미지 경고만) 및 통합검수함 타입 검사를 수행했다. CSS 회귀 테스트는 선언 계약만 검사하며 실제 모바일 브라우저 테스트를 대신하지 않는다. 통합검수함 모바일 실화면, iOS 키보드 및 실제 터치 기기 검증은 남아 있다.
