# 공식 수집 경로 현행성 재확인

## 엔제리너스

롯데이츠의 공식 엔제리너스 브랜드 메뉴 `https://www.lotteeatz.com/brand/angel`을 검색 결과와 공식 서비스 페이지 식별 정보로 확인했다. 기존 `www.angelinus.com` 메뉴·공지 링크를 현행 공식 메뉴 안내로 교체했다.

롯데이츠 robots는 OneulSinsang에 적용되는 일반 봇 그룹에 `Disallow: /`를 지정한다. 따라서 변경은 공식 출처 안내의 정정이지 자동 수집 복구가 아니다. 상품 페이지를 직접 크롤링하거나 다른 봇으로 위장하지 않았다. 출처 설명에도 자동 수집 보류를 명시했다.

## 투썸플레이스

검색 결과에서는 기존 d-mcdn 메뉴 경로와 dd-mo 공식 페이지가 확인되지만, 이번 환경에서 기존 메뉴 CDN과 dd-mo의 정책 요청을 정상 검증하지 못했다. www 공식 도메인의 정책 요청은 HTTP 403이었다. 검색엔진에 페이지가 있다는 이유만으로 수집 허용·현재 정상 동작을 추정하지 않는다. 기존 주소를 검증되지 않은 다른 URL로 자동 치환하지 않았다.

## 맘스터치

기존 www 도메인과 리다이렉트가 가리킨 비-www 도메인의 robots 요청 모두 홈페이지로 이동하는 302 응답이었다. 이를 유효한 robots 정책으로 취급하거나 자동 추적하지 않았다. 신상품 수집 경로와 정책을 함께 검증하기 전까지 기존 수집 코드의 URL은 유지한다.

상품·NEW·수동 검수 데이터는 변경하지 않았다. 정책 점검 보고서는 수정된 엔제리너스 URL을 기준으로 다시 생성한다. 현재 작업은 로컬이며 운영 배포 전이다.
