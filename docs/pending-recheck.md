## 안전 기준

- 공식 호스트 허용 목록과 robots.txt 확인 후 요청. 리디렉션은 자동으로 따라가지 않음.
- 가격 수집/노출, 실제 관리자 알림 발송, 수동 승인 덮어쓰기 없음.
- NEW 미확인을 NEW 종료나 판매 종료로 변경하지 않음.
- 최초 발견일과 기존 기록일 유지. 이번 재검수를 새 상품 발견으로 집계하지 않음.
- 상품별 점검 결과: `src/data/pending-recheck.json`. 이는 검수 대기 재점검 기록이며 전체 수집 운영 결과와 별개다.
- 재실행: `node --experimental-strip-types scripts/recheck-pending-products.ts`. 읽기 전용이며 결과를 출력할 뿐, 자동 승인/저장은 하지 않는다. 세븐일레븐 신상품 탭과 FOM NEW 대조는 각 전용 수집기로 별도 수행했다.
