# 피자헛 이미지 확인

공개 목록 API와 해당 공식 상세 페이지를 robots 게이트를 통해 점검했다. 현재 NEW인 RPPZ2275(쓰리스타 시그니처)는 저장 데이터에 이미지가 없으며 API의 thumb와 image도 모두 null이다. 상세 HTML은 동적 화면의 껍데기이고 상품 이미지는 없었다. og:image는 공통 kakao_20260701.jpg 배너로 상품 이미지로 사용하지 않았다. 추적 픽셀·외부 스크립트·배너 이미지는 요청하지 않았다.

기존 파서는 thumb/image를 읽는 코드 자체가 없었다. 같은 API 항목에 향후 문자열 이미지가 제공되면 공식 www/akamai 호스트의 HTTPS 이미지만 연결하도록 보완했다. 빈 필드·잘못된 주소·로고/공통 배너를 다른 이미지로 추측하지 않는다. 이미지 누락 때문에 NEW 상품을 제외하지 않는다. 두 필드가 계속 null이면 이 보완만으로 현재 상품 이미지가 복구되는 것은 아니다.

상품별 동적 이미지 데이터 경로의 검증은 남아 있다. 이번 점검에서는 상품 데이터·검수 상태를 수정하지 않았고 코드 변경은 로컬 미배포 상태다.

## 렌더링 이미지 근거 보완

사용자가 공식 화면의 img src를 제공했고, CDN robots 검사와 HEAD 요청에서 image/png·200을 확인했다. RPPZ2275_RPEG0056_RPDO0001_l.png를 해당 상품의 검증된 대체 주소로 관리한다. 파일명의 에지/도우 코드를 조합하거나 다른 상품에 전파하지 않는다.

목록 API에 이미지가 없으면 상세 HTML의 동일 상품 코드 img를 찾고, 없을 때 확인된 개별 주소를 사용한다. 각 대체 주소는 공통 robots 전송기를 거쳐 HEAD 이미지 응답을 확인한 경우에만 채택한다. 미확인·실패 시 상품을 버리거나 배너로 대체하지 않는다. 한 실행의 상세 보완은 최대 20개로 제한한다. 현재 HTML이 비어 있는 Angular 상품을 브라우저로 자동 렌더링하는 기능은 아니므로 다른 상품은 확인된 주소가 없으면 누락이 남을 수 있다.

현재 상품 JSON에는 imageUrl만 보완하며 최초 발견일·상품 ID·검수 상태는 유지한다.
