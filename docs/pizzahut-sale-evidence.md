# 피자헛 주문 가능 근거

기존 availabilityStatus=on_sale은 여러 수집기가 일반적으로 설정하므로 그 값만으로 주문 가능을 표시하지 않는다. 피자헛의 NEW 추출기는 판매 기간 안에 orderable=YES인 옵션이 실제 존재할 때만 후보를 만들며, 이 조건을 통과한 같은 상품에 공식 주문 가능 reference를 기록한다. 상품 링크·검증 API·확인 시각을 함께 저장하고 재수집 시 같은 판매 링크를 중복 누적하지 않는다. 다른 출시/판매 링크는 보존한다.

표시 로직은 피자헛·정확한 공식 상품 경로·검증 API·verified reference를 함께 확인한다. 통과하면 '공식 주문 가능 확인 (매장별 재고·배달 별도)'와 한국 시간의 확인 시각을 표시한다. 종료 기록은 '과거'로 구분한다. 실시간 재고·매장별 주문·배달 가능 여부를 보장하지 않는다. NEW 판별·자동 승인 기준은 변경하지 않는다.

공개 상세 화면과 통합검수함 canonical 소스를 수정했다. 기존 상품 데이터에 과거 근거를 추정해 소급 저장하지 않았으며, 새 판매 reference는 변경된 수집기 적용 후 성공 수집부터 생성된다. 현재 로컬 검증 상태이며 운영 미배포다. Sites 배포 승인 후 source helper로 hosted checkout에 두 공통/UI 파일을 반영해야 한다.
