# 공개 화면 개선 1–6 통합 작업

배포 전 로컬 구현. GitHub Pages 화면만 대상이며 ChatGPT Site·수집 기준·상품 데이터는 변경하지 않았다.

1. 검색·상품군·브랜드·세부 분류를 하나의 필터 패널로 정리. 현재 범위·상품 수와 검색/필터 초기화 제공. 상위 분류 변경 시 하위 분류 초기화.
2. `/search/` 정적 페이지에서 모든 공개 상품을 상품명·브랜드·세부 분류로 검색. 공백으로 나눈 검색어는 모두 일치하는 상품을 찾으며 대소문자·유니코드 표기를 정규화. 홈과 공통 헤더에 진입 링크. 카테고리 페이지에서는 해당 범위 내 검색.
3. 컴팩트 기본값 유지. 이미지 정사각형·상품명 최대 두 줄·하단 날짜 정렬. 컴팩트/카드/리스트 보기와 최근 발견순/출시 기록순을 구분. 최초 발견일은 한국 시간으로 표시하며 공식 출시일과 혼동하지 않음.
4. 홈의 주간/월간 요약을 접근성 기간 탭으로 통합. 기존 날짜 탭·상품군 이동·전체 목록·고정 높이 스크롤/더보기 유지. 숨긴 패널은 화면·접근성 트리에서 제외. 키보드 방향키/Home/End 지원.
5. 모바일 필터 접기/펼치기와 가로 스크롤 칩, 터치 가능한 44px 컨트롤 적용. 검색·정렬·보기 전환 영역은 좁은 화면에서 줄바꿈. 모바일 컴팩트 2열·카드 1열 유지.
6. 이미지 URL이 없거나 로딩 오류가 나면 브랜드·상품군·아이콘을 보여주는 공통 썸네일 적용. 홈 요약과 상품 목록에 함께 사용.

추가: 검색·필터·정렬·보기 설정을 URL에 유지해 링크 공유/새로고침 후 복원. 정적 export와 서버 렌더링을 지원하며 외부 검색 API·추적 도구·저장소를 추가하지 않음. 검색어는 URL에 포함되므로 민감한 정보 입력은 피할 것.

## 검증

- 테스트 171개, 타입 검사·정적 export 868개 페이지 통과. 린트 오류 0, 외부 img 관련 경고 2.
- 로컬 실제 브라우저: 기간 탭 전환, ‘스타벅스 라떼’ 검색 8건, 보기 전환, 새로고침 후 검색·보기 상태 복원, 상품군→브랜드 범위 변경 확인.
- GitHub Pages basePath(`/oneul-sinsang/`)의 최종 정적 출력에서도 MD 필터 17건과 접두 경로 링크를 확인했다.
- 모바일 반응형 CSS는 적용했으나 iOS/Android 실기기 검증은 하지 않았다. 운영 배포·운영 화면 변경 없음.

다음 배포는 공개 GitHub Pages만 필요하다. Site 재배포나 권한·DB 변경은 필요하지 않다.
