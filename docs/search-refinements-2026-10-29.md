# 검색·관심상품 필터 개선

## 동작

- 검색어·상품군·브랜드·세부 분류를 개별 해제할 수 있는 선택 조건 버튼을 추가했다.
- 상품군 해제 시 브랜드·세부 분류도, 브랜드 해제 시 세부 분류도 함께 초기화한다. 검색어·정렬·보기 방식·관심 목록 종류는 별도 변경하지 않는다.
- 필터 건수는 현재 검색어와 관심 목록 범위를 반영한다. 각 분류 단계는 자신의 선택과 하위 선택을 제외한 건수를 표시한다.
- 결과 0건에서 실제 결과가 생기는 조건 해제 방법과 예상 건수를 제안한다. 관심상품 복구도 저장한 목록 안에서만 계산한다.
- 0건인 미선택 분류는 비활성화하고, 선택 조건은 화면 상단에서 해제할 수 있다.
- 긴 검색어는 선택 조건 버튼에서 두 줄로 표시한다. 전체 검색어는 입력창·접근성 이름·툴팁에 유지한다.
- 조건 해제 후 검색 입력창으로 포커스를 돌려준다.

## 검증

검증일: 2026-10-29 (Asia/Seoul). 외부 운영 사이트 배포가 아닌 로컬 정적 빌드 결과를 사용했다.

- 전체 테스트 250개 통과. 필터 건수·관심 범위·조건 초기화·결과 복구 회귀 테스트 포함.
- 정적 빌드 907페이지 및 빌드 타입 검사 통과.
- lint 오류 0개, 기존 img 경고 2개.
- Playwright 실제 브라우저: 스타벅스 73개 상태에서 검색 결과 0건 → 검색어 해제로 73개 복구.
- 복구 후 브랜드 조건 유지, 검색 입력 포커스 복원, 새로고침 후 URL 조건 유지 확인.
- 320px·390px 화면에서 가로 넘침 없음. 120자 검색어의 선택 조건 텍스트 높이 36px (두 줄) 확인.
- 실제 관심상품 저장 후 관심 목록의 MD 건수 1개 확인.
- 관심상품의 결과 0건 → 1개 복구가 전체 공개 상품 892개로 범위를 넓히지 않는 것 확인.
- 관심상품의 세부 분류 개별 해제 확인.
